# Implement Auto-Location Weather Widget

This project involves building a widget that detects the user’s location (GPS/IP) and displays real-time weather data from OpenWeatherMap’s `current` API.

## Features

1. **Core Functionality (50%)**
    - Detects user's location via GPS/IP
    - Fetches real-time weather data from OpenWeatherMap's `current` API
    - Displays the fetched weather data on the widget

2. **UX Polish (30%)**
    - Provides a user-friendly interface
    - Displays weather data in an easy-to-understand format

3. **Innovation (20%)** *(Bonus)*
    - Provides additional weather-related information based on user's location
    - Allows users to customize the widget's appearance

## Tech Stack

- Language: JavaScript
- Framework: React
- Testing Framework: Jest

## Installation

1. Clone the repository to your local machine.
2. Navigate to the project directory.
3. Install the required dependencies by running `npm install`.
4. Start the application by running `npm start`.

## Usage

Once the application is running, the widget will automatically detect your location and display the current weather data. You can also customize the widget's appearance and view additional weather-related information.

## API Documentation

This project uses the OpenWeatherMap's `current` API to fetch real-time weather data. You can find the API documentation [here](https://openweathermap.org/api).

## Testing

This project uses Jest as the testing framework. To run the tests, navigate to the project directory and run `npm test`.

Please note that you need to have Jest installed globally on your machine. If you don't have it installed, you can do so by running `npm install -g jest`.
